출결 서류 대조 점검 프로그램 사용 안내

나이스 월별 출결 현황과 리로스쿨 결석신고서를 자동으로 맞춰 보고, 서류가 빠졌거나 내용이 어긋난 건을 찾아 주는 도구입니다. 설치할 것은 없고, HTML 파일 하나를 브라우저로 열면 됩니다.

준비 시간 약 3분 · 설치 불필요 · 자료는 컴퓨터 밖으로 나가지 않습니다

무엇을 해 주는가

매달 하시던 대조 작업을 대신합니다. 나이스에 올라온 출결 한 건 한 건에 대해 리로스쿨 결석신고서가 있는지 찾고, 있으면 학생 이름·출결 종류·기간·교시가 맞는지 봅니다. 그다음 담임이 손대야 하는 것만 목록으로 뽑아 줍니다.

  • 서류가 없는 건 — 나이스에는 있는데 리로스쿨 신고서가 없는 경우
  • 나이스에 없는 건 — 신고서는 올라왔는데 나이스 입력이 빠진 경우
  • 내용이 어긋난 건 — 조퇴 교시가 다르거나 출결 종류가 다른 경우
  • 증빙이 빠진 건 — 신고서는 맞게 올라왔는데 진료확인서·처방전 같은 첨부파일이 없는 경우
  • 생리결석 증빙 확인 — 리로스쿨에 첨부가 없는 생리결석을 모아, 따로 받았는지 확인하게 알려 줍니다
  • 결재만 남은 건 — 내용은 맞는데 부장·교감 결재가 안 끝난 경우
  • 학부모 안내 문자 — 신고서·증빙을 받아야 하는 학생별로 문구까지 만들어 줍니다

준비물

나이스 엑셀

월별 출결 현황을 엑셀로 내려받습니다.

리로스쿨 텍스트

결석신고서 인쇄 화면을 복사해 둡니다.

1. 나이스에서 엑셀 받기

출결현황및통계 화면에서 시작합니다.

  1. 월별 출결현황

    오른쪽 아래 버튼을 누르면 창이 열립니다.

  2. ‘셀병합’ 체크를 풉니다

    이것만은 꼭 확인해 주세요. 체크가 켜져 있으면 같은 학생의 여러 날짜가 한 칸으로 합쳐져 내려오고, 프로그램이 날짜를 읽지 못합니다.

  3. 월을 고르고 조회

    점검하려는 달로 맞춘 뒤 조회를 누릅니다.

  4. 엑셀다운로드

    내려받은 파일은 그대로 두면 됩니다. 열어서 고치지 마세요.

셀병합 체크를 푸는 것이 가장 흔한 실수입니다. 체크된 채로 받은 파일을 넣으면 출결 건수가 실제보다 적게 잡히거나 날짜가 비어 버립니다. 대조 실행 후 “출결 기록 N건 인식”에 나오는 숫자가 나이스 화면의 Total 숫자와 같은지 한 번 보세요.

2. 리로스쿨에서 텍스트 복사

결석신고서 목록에서 이번 달 건을 열고 인쇄 화면을 띄웁니다.

  1. 인쇄 버튼을 누릅니다

    오른쪽 위 인쇄를 누르면 위와 같은 화면이 나옵니다.

  2. 전체 선택 후 복사

    Ctrl+A로 화면을 전부 고르고 Ctrl+C로 복사합니다. 맥은 ⌘+A, ⌘+C입니다.

  3. 창을 닫습니다

    복사만 되면 되니 인쇄는 하지 않아도 됩니다.

여러 건을 한 번에 복사하는 것이 편합니다. 한 건씩 복사하시는 경우에는 프로그램의 붙여넣기 칸에 이어서 붙여넣으면 됩니다. 프로그램이 문서번호를 기준으로 알아서 나눕니다.

결재선까지 함께 복사해 주세요. 제목 옆의 완료·서명대기 표시가 같이 들어와야 결재가 끝났는지도 함께 점검됩니다. 증빙자료 칸의 첨부파일 이름(예: IMG_1217.png)도 같이 복사되어야 증빙 첨부 여부가 점검됩니다. 화면을 끝까지 다 뜬 뒤에 전체 선택하면 됩니다.

3. 프로그램에 넣고 실행

  1. HTML 파일을 엽니다

    파일을 더블클릭하면 크롬·엣지 같은 브라우저에서 열립니다. 엑셀을 읽는 기능 때문에 인터넷은 연결되어 있어야 합니다.

  2. 왼쪽에 엑셀을 올립니다

    칸을 눌러 파일을 고르거나, 파일을 끌어다 놓아도 됩니다.

  3. 오른쪽에 복사한 내용을 붙여넣습니다

    Ctrl+V로 붙여넣으면 “문서번호 N개가 보입니다”가 뜹니다. 이 숫자가 실제 신고서 건수와 맞는지 여기서 먼저 확인하세요.

  4. 대조 실행

    양쪽이 다 들어오면 버튼이 켜집니다.

4. 인식 결과 확인

나이스 기록과 신고서를 한 줄에 놓은 표가 나옵니다. 손볼 것이 있는 줄은 주황색으로 칠해집니다. 위쪽 ‘확인 필요만 보기’를 켜면 그 줄만 남습니다.

대조 완료이름·종류·기간·교시가 모두 맞습니다없습니다

대조 규칙

  • 학생 신청기간과 담임 승인기간이 다르면 승인기간이 기준입니다. 학생이 잘못 올린 것을 담임이 고쳐 승인했기 때문입니다.
  • 조퇴는 교실을 나간 교시, 지각은 마지막으로 빠진 교시, 결과는 앞뒤 교시를 모두 봅니다.
  • 리로스쿨의 0교시는 나이스의 조회로 봅니다.
  • 미인정으로 시작하는 출결은 증빙 대상이 아니라 대조에서 빼 둡니다.
  • 기타 출결과 경조사 출석인정은 리로스쿨 신고서 대상이 아니라 담임 확인 항목으로 갑니다.
  • 증빙 첨부 여부는 신고서의 증빙자료 칸에 파일 이름(jpg·png·pdf 등)이 있는지로 봅니다. 사진이 한 장이라도 붙어 있으면 첨부된 것으로 봅니다. 사진 내용이 맞는 서류인지까지는 알 수 없습니다.
  • 생리결석은 리로스쿨이 아니라 담임이 파일을 따로 받는 경우가 많아, 첨부가 없으면 오류가 아니라 확인 알림으로 따로 모아 줍니다. 리로스쿨에 파일이 붙어 있으면 알림에서 빠집니다.
  • 신고서 사유에 “진료확인서 제출하겠습니다”라고 적혀 있어도, 실제 파일이 없으면 증빙 없음으로 잡습니다.

5. 점검 보고서와 안내 문자

‘보고서 만들기’를 누르면 해야 할 일이 항목별로 정리됩니다. 하나씩 체크하면 진행률이 올라가고, 다 채우면 마감 가능 상태가 됩니다. 체크 표시는 화면에서만 유지되니 기록으로 남기시려면 인쇄 버튼으로 PDF 저장을 해 두세요.

학부모 안내 문자

서류를 받아야 하는 학생별로 문자 문구가 자동으로 만들어집니다. 같은 학생이 여러 날 걸려 있으면 한 통으로 묶입니다.

문자에는 세 가지가 들어가며, 한 학생에게 여러 가지가 걸리면 한 통 안에서 문단을 나눠 안내합니다.

종류문자 내용
신고서 미제출리로스쿨에 결석신고서를 작성하고 증빙을 첨부해 제출해 달라는 안내
증빙 미첨부이미 낸 신고서에 진료확인서·처방전 등을 첨부해 달라는 안내
생리결석 증빙확인 서류를 담임교사에게 따로 보내 달라는 안내 (이미 보냈다면 알려 달라는 문장 포함)
  • 보고서에서 체크한 건은 문자에서 빠집니다. 리로스쿨 밖에서 서류나 파일을 직접 받으셨다면 문자를 복사하기 전에 먼저 체크해 주세요. 특히 생리결석은 기본으로 문자 대상에 들어가 있으니, 이미 받은 학생은 꼭 체크하세요.
  • 위쪽에 학급과 성함을 넣으면 모든 문구에 반영됩니다. 매달 다시 넣으셔야 합니다.
  • 증빙 안내는 출결 종류에 따라 달라집니다. 질병이면 진료확인서, 기타면 사유 증빙으로 나갑니다.
  • 문구는 그 자리에서 고쳐 쓸 수 있고, 고친 뒤에 학급명을 바꿔도 손댄 문구는 그대로 둡니다.
  • 교외체험학습 보고서 안내는 따로 묶여 있습니다. 프로그램은 보고서를 받았는지까지는 알 수 없으니, 아직 못 받은 학생에게만 보내세요.

알아 두실 것

  • 자료는 컴퓨터 밖으로 나가지 않습니다. 엑셀과 붙여넣은 내용은 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다. 엑셀을 읽는 프로그램만 인터넷에서 불러옵니다.
  • 체험학습은 나이스 사유로 알아냅니다. 사유에 체험학습·교외체험·현장체험이 들어 있어야 잡힙니다. 학교에서 다른 말을 쓰신다면 알려 주세요.
  • 이름이 같은 학생이 있으면 사람이 한 번 더 봐야 합니다. 프로그램은 이름과 날짜로 맞추기 때문입니다.
  • 결과가 이상하면 대개 셀병합 때문이거나, 리로스쿨 복사가 일부만 된 경우입니다. 1단계에서 인식된 건수부터 확인해 보세요.
